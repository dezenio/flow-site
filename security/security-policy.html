Flow

Security Policy

Dezenio, LLC · Effective November 11, 2026 · Reviewed at least once a year

Purpose

Sets out how Dezenio protects Flow and the data of people who use it.

Data handling

  • Flow processes user data only on the user's devices and in services the user connects with their own sign-in. Dezenio operates no servers for Flow and does not collect, receive or store user data, OAuth tokens or API keys.
  • Tokens and keys are stored in the device Keychain; app data stays in the app's sandbox, encrypted by the operating system, and in the user's own OneDrive folder.
  • Flow requests only the permissions it uses, and does not log message content, meeting content or credentials.

Access control

  • Access to Flow's source code, signing certificates and developer accounts (Apple, GitHub, Zoom, Microsoft Entra, Anthropic) is limited to Dezenio personnel who need it.
  • These accounts require multi-factor authentication.
  • Access is reviewed at least once a year and removed promptly when no longer needed.

Secure development

All changes follow the Secure Software Development Lifecycle, including code review, automated tests, secret checks, and SAST before release.

Reporting a security issue

Report suspected vulnerabilities to support@dezenio.com with "Security" in the subject. We acknowledge reports within 3 business days and handle them under the Vulnerability Management Procedures.

Compliance

Anyone working on Flow is expected to follow this policy. Exceptions require the owner's written approval and are recorded with their reason and an end date.
